How to go live on the day
  1. In Excel Online / OneDrive, make GeoAI, Geography and Society.xlsx available offline so it syncs to this computer (OneDrive folder).
  2. Open this page in Chrome or Edge, click Connect live spreadsheet… and pick that synced file. The page re-reads it every few seconds, so new survey responses appear as OneDrive syncs them down (usually within a minute).
  3. Next time the page remembers the file — you just click once to re-grant access. In other browsers, use Load file (or drag the .xlsx onto the page) and reload it manually.
  4. Your data never leaves the browser; the page only reads the file.
